## 1. Principio Rector: Monolito Modular MVC Proporcional a la Complejidad (Cero Sobreingeniería)

Siguiendo la directiva de la Fase J (*"No impongas todas las capas a módulos simples que no las necesitan. Conserva las rutas HTTP, nombres de modelos, aliases Sequelize y contratos públicos durante la futura transición"*), los **23 módulos activos** de `backend/src/modules/` se clasifican en **3 Perfiles Arquitectónicos MVC**:

| Perfil MVC | Módulos del Proyecto Incluidos | Capas Obligatorias | Capas Opcionales (No Forzadas) |
| :--- | :--- | :--- | :--- |
| **Perfil A — Módulo Simple CRUD / Catálogo / Infraestructura (`10` módulos)** | `health`, `auth`, `users`, `roles`, `permissions`, `areas`, `notifications`, `reports`, `dashboard`, `catalogs/supplier` | `*.routes.js` $\rightarrow$ `*.controller.js` *(0 Sequelize)* $\rightarrow$ `*.service.js` $\rightarrow$ `*.model.js` (vía `database/models/index.js`) + `*.validator.js` | No requieren separar `repositories/` ni `rules/` si el servicio tiene `< 300` líneas y no contiene fórmulas matemáticas complejas. |
| **Perfil B — Módulo Operativo de Complejidad Media (`9` módulos)** | `materials` (y sus 7 subcatálogos), `formulas`, `reception`, `qrcodes`, `wip`, `corte`, `laminado`, `globo`, `audit` | `*.routes.js` $\rightarrow$ `*.controller.js` *(0 Sequelize)* $\rightarrow$ `*.service.js` *(Frontera transaccional)* $\rightarrow$ `rules/*.js` *(Reglas puras)* + `models/*.model.js` | `repositories/` solo para consultas con `include` profundos reutilizados en más de un servicio. |
| **Perfil C — Módulo Industrial Complejo con Fachada Delegadora (`4` módulos monolíticos)** | `extrusion` (`8,303` líneas en `extrusion.service.js`), `traceability` (`3,629` líneas), `telares` (`2,846` líneas), `warehouse` (`1,555` líneas) | `*.routes.js` $\rightarrow$ `*.controller.js` *(0 Sequelize)* $\rightarrow$ **`<modulo>.service.js` (Fachada 100% retrocompatible)** $\rightarrow$ `services/<subcaso>.service.js` $\rightarrow$ `rules/*.js` *(Funciones puras deterministas)* + `repositories/<modulo>.repository.js` *(Recibe `{ transaction }`)* $\rightarrow$ `models/*.model.js` | Todas las capas separadas para mantener cada archivo `< 600–800` líneas sin romper ningún consumidor externo. |
